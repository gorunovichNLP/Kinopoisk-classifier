AutoModelForSequenceClassification.from_pretrained("./model") (из Transformers, Hugging face), происходит два шага: сначала AutoConfig читает config.json и по полю model_type + architectures понимает, какой класс модели инстанцировать и с какими размерностями, потом создаётся пустой каркас нужной формы, и в него загружаются веса из safetensors. То есть config подаётся в конструктор модели — он определяет форму, веса заполняют её содержимым.
